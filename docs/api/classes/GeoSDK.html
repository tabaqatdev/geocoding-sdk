    Class GeoSDK

    @tabaqat/geocoding-sdk

    Browser-based geocoding SDK for Saudi Arabia using DuckDB-WASM Supports Arabic and English with zero backend dependencies

    Uses H3 tile-based partitioning for ultra-fast queries H3 tiles (~220KB avg) provide <4s reverse geocoding Initial load is ~140KB (index + boundaries)
